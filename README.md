# Personal Stock Screener PWA

เว็บแอปพลิเคชัน Progressive Web App (PWA) สำหรับคัดกรองหุ้นส่วนตัว (S&P 500 และ SET) ทำงานร่วมกับ GitHub Actions และ Yahoo Finance

---

## 📖 คู่มือวิธีเพิ่ม หรือ ลดรายชื่อหุ้น (Top 150 Tickers)

หากต้องการปรับเปลี่ยนรายชื่อหุ้นในระบบ สามารถทำตามขั้นตอนง่ายๆ ดังนี้ครับ:

1. เข้าไปที่หน้า GitHub Repository ของโปรเจกต์นี้
2. คลิกเข้าไปที่โฟลเดอร์ **`scripts`** แล้วเลือกไฟล์ **`fetch_yahoo.py`**
3. กดปุ่มดินสอ (**Edit**) เพื่อแก้ไขโค้ด
4. เลื่อนหาตัวแปร **`tickers = [...]`** ด้านบนสุดของไฟล์
   * **อยากเพิ่มหุ้น:** พิมพ์ชื่อ Ticker ต่อท้ายลงไปในเครื่องหมายคำพูด (เช่น `'TSLA'`, `'ADVANC.BK'`) 
   * **อยากลดหุ้น:** ลบบรรทัดชื่อหุ้นตัวนั้นออก
5. กดปุ่ม **Commit changes...** (มุมขวาบน) เพื่อบันทึก
6. ไปที่แท็บ **Actions** ด้านบนของ GitHub -> เลือก Workflow ชื่อ **`Daily Stock Data Update`** -> กดปุ่ม **`Run workflow`** เพื่อสั่งให้ระบบดึงข้อมูลชุดใหม่มาอัปเดตทันที (รอประมาณ 1-2 นาทีให้ขึ้นติ๊กถูกสีเขียว)
